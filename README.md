
# Movie Reservation System

A college-level Data Science using Python project built with Streamlit, SQLite and Pandas.

## Features
- Movie browsing
- Theatre/show selection
- Interactive seat selection
- Ticket booking
- Booking cancellation
- Booking history
- SQLite database
- Revenue and ticket analytics
- Admin dashboard
- Data science charts

## Run
```bash
python3 -m pip install -r requirements.txt
streamlit run app.py
```

Open the local URL shown by Streamlit.
