
# MOVIE RESERVATION SYSTEM USING PYTHON

## 1. Abstract
The Movie Reservation System is a Python-based application that automates movie browsing, show selection, seat reservation, booking management and sales analysis. SQLite is used for persistent storage and Streamlit provides the user interface. Pandas is used for data analysis and visualization.

## 2. Objectives
1. Provide a simple movie booking interface.
2. Display movies, theatres and show timings.
3. Prevent double booking of seats.
4. Store booking information in a relational database.
5. Provide booking cancellation and history.
6. Analyze ticket sales and revenue.

## 3. Technologies
Python, Streamlit, SQLite, Pandas, Matplotlib, Scikit-learn.

## 4. Modules
- User module
- Movie module
- Show module
- Seat module
- Booking module
- Admin module
- Analytics module

## 5. Database Tables
users, movies, shows, seats, bookings, booking_seats.

## 6. Data Science
The project converts booking records into a dataset and calculates movie popularity, ticket sales and revenue. Bar charts are used to communicate results.

## 7. Future Enhancements
Real login authentication, payment gateway, QR-code tickets, email notifications, movie recommendation and demand prediction.

## 8. Conclusion
The system demonstrates how Python can combine software development, database management and data science into one practical application.
